# Data Model: Trainer Command Notification Infrastructure

**Feature**: [006-trainer-command-notification](spec.md)
**Date**: 2026-08-29

## Entities & Data Structures

### 1. Protobuf Wire Models

#### `TrainerRegistrationRequest`
The registration message sent by the Trainer to initiate the server-streaming command subscription.
- **Fields**:
  - `trainer_id` (`string`, required): Unique string identifier of the subscribing Trainer node (e.g., `"trainer-node-01"`).

#### `CommandEnvelope`
The generic wrapper for all commands sent over the gRPC stream from Coordinator to Trainer.
- **Fields**:
  - `id` (`string`, required): Unique message UUID generated by the Coordinator.
  - `type` (`string`, required): Name of the command matching `CommandType` (e.g., `"StartTraining"`).
  - `data` (`string`, required): UTF-8 JSON-encoded payload string containing the command attributes.

---

### 2. Application Domain Models

#### `CommandType` (Enum)
Supported command types in the system.
- **Values**:
  - `StartTraining = "StartTraining"`

#### `StartTrainingCommand` (Payload Model)
Strongly typed model representing the payload for initiating a training session.
- **Fields**:
  - `trainingClientNodeId` (`string`, required): Identifier of the client node that initiated and owns the training session.
  - `sessionId` (`string`, required): Unique identifier (GUID string) of the training session.
- **JSON Serialization (camelCase)**:
  ```json
  {
    "trainingClientNodeId": "client-node-01",
    "sessionId": "3fa85f64-5717-4562-b3fc-2c963f66afa6"
  }
  ```

#### `CommandDispatchResult` (Coordinator Result Model)
The outcome returned by `ICommandCenter.SendAsync`.
- **Fields**:
  - `isSuccess` (`bool`): `true` if the command was successfully serialized and written to the active stream; `false` otherwise.
  - `commandId` (`string`): The UUID assigned to the command.
  - `errorMessage` (`string?`): Reason for failure if `isSuccess == false` (e.g., `"Trainer 'trainer-node-01' is not connected"`, `"Transport write error"`).

---

### 3. Coordinator In-Memory Connection State

#### `TrainerConnection`
Represents an active server-streaming connection in the Coordinator's `TrainerConnectionManager`.
- **Fields**:
  - `TrainerId` (`string`): Unique identifier of the connected Trainer.
  - `ConnectedAt` (`DateTime`): Timestamp when the stream was established.
  - `MessageChannel` (`Channel<CommandEnvelope>`): Thread-safe queue used to sequence writes to the gRPC response stream writer.
  - `CancellationTokenSource` (`CancellationTokenSource`): Linked CTS used to cancel and clean up the connection when superseded or closed.

---

## State Transitions & Lifecycle

### Connection Lifecycle
```text
[Trainer Startup / Reconnect]
          │
          ▼
   Initiate RPC: SubscribeCommands(trainer_id)
          │
          ▼
   [Coordinator Connection Manager]
          ├── If existing connection present -> Complete old channel & replace
          └── Register new TrainerConnection in ConcurrentDictionary
          │
          ▼
   [Active Streaming State]
          ├── Coordinator calls CommandCenter.SendAsync() -> Enqueues to TrainerConnection channel -> Writes to stream
          │
          ▼
   [Connection Drop / Client Disconnect / Server Shutdown]
          ├── context.CancellationToken fires -> Remove TrainerConnection from dictionary
          └── Trainer waits 5s -> Reconnects with same trainer_id
```

### Command Dispatch Lifecycle
```text
Coordinator Application
          │
          ▼
  ICommandCenter.SendAsync(trainerId, StartTrainingCommand)
          ├── Generate UUID id
          ├── Serialize StartTrainingCommand to JSON camelCase string
          ├── Look up TrainerConnection in TrainerConnectionManager
          │     ├── NOT FOUND -> Return CommandDispatchResult(isSuccess=false, "TrainerNotConnected")
          │     └── FOUND -> Enqueue CommandEnvelope into MessageChannel
          │           ├── Channel full / closed -> Return CommandDispatchResult(isSuccess=false, "TransportError")
          │           └── Stream writer sends envelope -> Return CommandDispatchResult(isSuccess=true)
          │
          ▼ (over gRPC wire)
Trainer Transport
          │
          ▼
  CommandDispatcher.dispatch(envelope)
          ├── Look up registered handler for envelope.type
          │     └── UNKNOWN -> Log warning, safely discard
          ├── Deserialize envelope.data JSON to typed StartTrainingCommand
          │     └── DESERIALIZATION ERROR -> Log error, skip invocation
          └── Invoke StartTrainingHandler.handle(start_training_command)
```
